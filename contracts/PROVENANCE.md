# Wire-contract fixtures — vendored snapshot

Источник правды — **haia-cp**, `contracts/policy/v1/`.
Здесь лежит **снапшот** для контрактного теста SDK, чтобы haia-js был
самодостаточен (в его CI haia-cp не склонирован).

- Источник: `Haia-Finance/haia-cp`, ветка `had-340-journal-to-events`, `6f3b9c1`
- Потребитель: `packages/core/src/contract.test.ts`

## Дрейф

`contract.test.ts` при наличии `../haia-cp` локально сверяет снапшот с
источником побайтово и падает при расхождении — так копия не разъезжается с
правдой незаметно. В CI (без haia-cp) эта проверка пропускается, тест идёт по
снапшоту.

## ⚠️ Механизм провизорный

Вендоринг выбран как единственный, работающий в CI сегодня. Кандидаты на
замену, когда появится потребность версионировать контракт независимо:
публикуемый пакет `@haia/policy-contract` из haia-cp либо git-submodule.
Решение не финализировано — при ревизии обновить этот файл и `contract.test.ts`.

## Обновление снапшота

```
cp -R ../haia-cp/contracts/policy/v1/. contracts/policy/v1/
```

и зафиксировать новый sha источника выше.
